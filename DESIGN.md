# Оформление Amazing RP

Собственная графика в серии Linux RP: светлая бумага, тёмный терминал, пиксельное название, фиолетовый акцент и простая навигация. Источник — assets/create_art.py; результаты — PNG и SVG. Для пересборки нужны Python 3, pycairo и DejaVu. На GitHub зависимости не требуются. Изображения хранятся в репозитории и снабжены alt-текстом.
