# Если установка или запуск остановились

## Сначала проверьте состояние

```bash
bash install-amazing-rp.sh --check
```

Не удаляйте игру и префикс наугад. Если скрипт остановился, сохранённые данные остаются на месте.

| Сообщение или симптом | Действие |
| --- | --- |
| Не найден install-amazing-rp.sh | Откройте терминал в корне распакованного или клонированного проекта |
| Скрипт запущен от root | Запустите без sudo; права запрашиваются только для системных пакетов |
| Префикс активен | Закройте Amazing и официальный лаунчер, затем повторите |
| Найден неподготовленный существующий префикс | Оставьте его и выберите новый каталог через --prefix |
| Не совпала SHA-256 | Повторите загрузку или обновите проект; проверку суммы не отключайте |
| Не создан native CLR или не прошла PowerShell-проба | Откройте журнал соответствующего этапа; не выдавайте наличие EXE за успешную установку |
| Отсутствует AmazingService | Откройте официальный updater, дождитесь обновления, закройте и повторите скрипт |
| Изменилась версия DXVK или совместимого файла | Обновите проект; адрес таблицы привязан к проверенной сборке |
| Соединение разорвано на форме входа | Используйте «Переподключиться» в игровом окне |
| Чёрные полосы или режимы другого экрана | Закройте игру и лаунчер и повторите запуск; см. [экран](displays.md) |

## Журналы

Обычный запуск: `~/.local/state/linux-amazing-rp/logs/amazing-compat.log`.

Установка: `~/.local/state/linux-amazing-rp/install-logs/<имя-префикса>/`.

Журналы доступны только владельцу. Лаунчер может записывать токены; не публикуйте сырые журналы без проверки. Для обращения достаточно описания симптома, названия этапа и обезличенного фрагмента ошибки.

## Повторить подготовку

Обновите проект через Git либо распакуйте новый ZIP. Закройте Amazing и запустите `bash install-amazing-rp.sh`. Существующий рабочий профиль будет использован повторно.

Не устанавливайте случайные DLL из сторонних архивов. Генераторы совместимости проверяют известную версию DXVK и вызывают настоящие API. Они не заменяют игровые файлы.

## Восстановить исходные библиотеки профиля

```bash
python3 ~/.local/share/linux-amazing-rp/compat-20261109/restore.py --restore-original
```

Откат останавливает только выбранный профиль Amazing, проверяет хеши и восстанавливает сохранённые библиотеки и параметры Debug. При наличии резервной копии возвращается прежняя команда запуска. Папка игры и пользовательские данные не очищаются. Системные пакеты и Windows-компоненты при таком откате не удаляются.
