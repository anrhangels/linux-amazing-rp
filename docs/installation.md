# Установка Amazing Online на Linux

Главная команда — `bash install-amazing-rp.sh` из корня распакованного или клонированного проекта. Не запускайте её через sudo и не скачивайте отдельно только этот файл: ему нужны входящие в репозиторий Python-скрипты, настройки и C#-пробы.

## Подготовка

Нужны графическая сессия Linux x86_64, интернет, драйвер Vulkan и место для игры. Драйвер видеокарты устанавливается средствами вашей системы. Установщик добавляет Flatpak и инструменты через пакетный менеджер, затем готовит отдельный профиль Amazing.

Для системных пакетов есть команды Arch/CachyOS/Manjaro, Debian/Ubuntu/Mint, Fedora и openSUSE. На неизменяемых системах подготовьте зависимости штатными средствами и используйте `--no-system-packages`.

## Git

```bash
git clone https://github.com/anrhangels/linux-amazing-rp.git "$HOME/linux-amazing-rp"
cd "$HOME/linux-amazing-rp"
bash install-amazing-rp.sh
```

Если Git отсутствует, выберите ZIP или установите Git через пакетный менеджер. Если папка уже существует, откройте её и обновите через `git pull --ff-only`; не удаляйте установленную игру.

## ZIP

Скачайте **Code → Download ZIP**, распакуйте архив, откройте терминал внутри `linux-amazing-rp-main` и выполните `bash install-amazing-rp.sh`.

## Что происходит

1. Скрипт показывает план и запрашивает подтверждение. Пароль Linux вводится только при установке системных пакетов; невидимый ввод пароля нормален.
2. Устанавливаются Faugus, зафиксированная GE-Proton и UMU.
3. В отдельном префиксе подготавливаются native .NET 4.8, VC++, DirectX и PowerShell 5.1.
4. Загружается официальный AmazingSetup. Если он открыл лаунчер, закройте окно, чтобы скрипт продолжил настройку.
5. Проверяется AmazingService, собираются локальные исправления и выполняются API-пробы.
6. Создаются команда `amazing` и ярлык **Amazing RP**.
7. Откройте лаунчер, дождитесь загрузки клиента, выберите сервер и нажмите «Играть».

Первая подготовка включает крупные загрузки Microsoft-компонентов и Proton. Скрипт использует уже скачанные компоненты только при совпадении контрольных сумм. Он не устанавливает Windows Service Pack: из проверенного пакета извлекается только инструмент распаковки WMF; системная msdelta Wine не заменяется.

## Полезные параметры

```bash
bash install-amazing-rp.sh --check
bash install-amazing-rp.sh --plan
bash install-amazing-rp.sh --yes
bash install-amazing-rp.sh --no-system-packages
bash install-amazing-rp.sh --installer "$HOME/Загрузки/AmazingSetup.exe"
bash install-amazing-rp.sh --prefix "$HOME/Games/amazing-rp/another-profile"
```

`--check` и `--plan` ничего не устанавливают и не меняют. `--yes` подтверждает показанные действия. Свой установщик выбирайте с официального сайта.

`--prefix` разрешает отдельный каталог внутри `~/Games/amazing-rp/`; исторический `prefix` не изменяется. Неизвестный существующий каталог не перезаписывается. Для отдельных испытаний есть `--no-shortcuts`: он не меняет основную команду запуска.

## Повторная установка

Закройте Amazing и повторите главный скрипт. При найденном рабочем профиле настройки и данные сохраняются, обновляются команды и файлы запуска. Незнакомые или изменённые библиотеки не затираются автоматически.

Установщик хранит состояние этапов, журналы и резервные копии в `~/.local/state/linux-amazing-rp/`. Настройки рабочего профиля — `~/.local/share/linux-amazing-rp/settings.json`. Игровые файлы получает официальный лаунчер; он же обновляет клиент.

## Запуск

```bash
~/.local/bin/amazing
```

Или ярлык **Amazing RP** в меню приложений. Для Hyprland используется рабочий стол 1; экран подбирается перед запуском. Подробнее — [настройка экрана](displays.md).
