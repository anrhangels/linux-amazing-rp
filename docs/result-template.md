## Публикация

Приложите небольшой релевантный фрагмент и, если возможно, обезличенный полный текстовый журнал. Удалите токены, пароли, почту, nickname/аккаунт, персональные пути и сетевые данные, которые не нужны для анализа. Дамп памяти может содержать секреты даже при безобидном имени файла; публично его не прикладывайте без проверки содержимого. Сохраните приватный оригинал, чтобы обезличивание не уничтожило доказательство.

Не прикладывайте клиент, DLL/ASI или игровые ресурсы. Для идентификации достаточно версии и хешей. Если утверждаете успешный запуск, укажите вход на сервер, управление персонажем, длительность сессии и повторяемость.
